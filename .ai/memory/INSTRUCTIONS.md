# Instrucoes de memoria

Use esta memoria com Codex e Claude Code.

- Leia `MEMORY.md` no inicio de uma sessao que possa tocar arquitetura,
  seguranca, fluxo de trabalho ou regras de negocio.
- Salve somente fatos duraveis, especificos e verificados que surpreenderiam
  uma sessao futura.
- Nao salve segredos, valores de ambiente, transcricoes, prazos temporarios ou
  fatos que o codigo e a historia Git ja deixam obvios.
- Para cada fato, prefira um topico em `topics/` e uma linha curta no indice.
- Mantenha o indice abaixo de 130 linhas. Antes de adicionar, deduplicate,
  mova detalhes para o topico apropriado e confirme a leitura do arquivo.
- Nunca apague uma memoria sem preservar o fato em um topico valido e ler o
  arquivo de volta.
